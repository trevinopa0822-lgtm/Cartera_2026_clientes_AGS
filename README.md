# Dashboard de facturación y cobranza

Publicar en GitHub Pages:

1. Crea un repositorio nuevo en https://github.com (público, o privado si tu plan lo permite).
2. Sube estos 3 archivos a la raíz del repositorio: `index.html`, `.nojekyll` y este `README.md`.
3. Ve a **Settings > Pages**.
4. En **Source** elige **Deploy from a branch**, rama **main**, carpeta **/(root)**. Guarda.
5. Espera 1-2 minutos. GitHub mostrará la URL, con este formato:
   `https://TU-USUARIO.github.io/TU-REPOSITORIO/`
6. Abre esa URL en Safari (iPhone) o cualquier navegador, pega la URL `/exec` de Apps Script en el cuadro de texto y pulsa Actualizar.

Cada vez que reemplaces `index.html` con una versión nueva, GitHub Pages se actualiza solo en 1-2 minutos.
